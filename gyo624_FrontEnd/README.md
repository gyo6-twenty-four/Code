# 교육24 프론트엔드

React 19 + Vite로 구현한 교사·학교 관리자용 학생 기록 관리 화면입니다.

현재 App은 사용자 제공 `API_명세서.md` v1.0.0의 REST 계약을 사용하는 `src/api` 화면으로 연결됩니다. 브라우저 저장소의 예시 계정·학생 기록으로 로그인/저장을 대신하지 않습니다.

## 실행

```sh
npm install
cp .env.example .env.local
npm run dev
```

개발 API 프록시는 기본 `http://127.0.0.1:8080`입니다. `.env.local`의 `API_PROXY_TARGET`으로 조정하고 개발 서버를 재시작합니다. 운영 빌드의 API 경로는 `VITE_API_BASE_URL`로 지정합니다. `/api/v1`을 제공하는 HTTPS 프록시 구성을 권장합니다. VITE 환경 변수에 비밀정보를 넣지 않습니다.

```sh
npm run lint
npm test
npm run build
```

## 기능

- 서버 로그인, /me 계정 역할, 세션 복원·토큰 갱신·로그아웃
- 초대 토큰 확인·최초 비밀번호 설정·비밀번호 재설정
- 온보딩, 프로필·알림·비밀번호·관리자 학교 설정
- 서버 학급/학생 ID에 기반한 관찰 CRUD·미래 날짜 차단·일괄 사전 검증과 저장
- 진로 기록 CRUD, 생기부 보드·임시 저장·검사·제출·이력 복원
- 서버 내보내기 미리보기·비동기 상태·보호 다운로드
- 학년도 간 이관 미리보기·충돌 정책·상태·대기 취소
- 알림 목록·읽음 수·전체 읽음·삭제
- 관리자 집계, 교사 초대/권한/상태, 학급/학생 명단, 파일 검증·등록, 시간표 및 감사 로그
- 교사 시간표 조회, 관리자 시간표 편집, 달력, 학급 우선 표시
- 요청한 범위대로 실제 오디오 없이 수업 녹음 상태 UI 유지

명세에 없는 평가·수업 메모·수업 교체의 로컬 저장 메뉴는 활성 경로에서 제외했습니다. 기존 소스와 로컬 데이터는 보존하며 자동 업로드하지 않습니다.

## 연결 상태와 확인 사항

**명세 기반 프론트 요청을 구현한 상태이며 기존 로컬 백엔드와의 통합 완료를 뜻하지 않습니다.** 현재 백엔드의 `/auth/me`, 최상위 토큰 응답, Long ID 등은 명세의 `/me`, data/meta 응답, UUID와 다릅니다. 백엔드는 변경하지 않았습니다.

명세에서 생략된 DTO·업로드 방식·경고 승인 필드 등 합의 항목과 화면별 연결 주소, 검증 범위는 [API 연결 기록](docs/api-integration.md)에 정리했습니다. 서버와 계약을 맞춘 뒤 실제 서버 통합 검증이 필요합니다.
