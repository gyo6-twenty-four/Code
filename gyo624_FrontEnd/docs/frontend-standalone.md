# 독립 프론트엔드 전환 · 2026-10-28

## 변경 목적

백엔드 개발 일정과 관계없이 UI를 수정하고 화면 흐름을 확인하도록 분리했습니다. React 화면과 브라우저 내부 저장소만 실행합니다. `gyo624_BackEnd`, 실제 DB, 서버 프로세스는 이번 작업에서 수정하지 않았습니다.

## 삭제한 기능과 이유

1. 녹음 페이지·메뉴·라우트·화면 컴포넌트와 녹음 전용 스타일: 요청에 따라 기능 자체 제거.
2. 관찰 공개범위·태그: 입력 부담을 줄이기 위해 입력란·저장 데이터·표시 제거. 관찰 범주는 유지.
3. 기록 내보내기: 메뉴·라우트·활성 화면·다운로드 동선 제거. 비활성 구형 화면의 관련 항목도 정리.
4. 파일 업로드/바이러스 검사·양식 다운로드: 현재 프론트 UI 작업에 필요하지 않아 활성 명단·시간표 화면에서 제거.
5. 서버 API 프록시와 자동 요청: Vite에서 제거. 브라우저의 로컬 데이터 처리로 전환.
6. 외부 전송을 했다는 안내: 실제 이메일을 보내지 않으므로 해당 성공 문구 제거.

기존에 비활성화되어 있던 평가·수업 교체 화면은 이번에 새로 활성화하지 않았습니다. 과거 초안의 모든 기능을 복원한 변경은 아닙니다. 사용하지 않는 나머지 구형 소스는 활성 화면에서 참조하지 않으며 이번 요청 범위 밖의 기능을 일괄 삭제하지 않았습니다.

## 글자와 레이아웃 수정

- 제목·설명·버튼에 한국어 단어 단위 줄바꿈과 긴 문자열 넘침 처리를 적용.
- 폼·그리드 자식의 최소 너비를 해제해 좁은 화면에서 옆 칸을 밀어내는 문제 방지.
- 버튼의 고정 높이를 내용에 맞는 높이로 변경하고 터치 영역 유지.
- 로그인/초기 설정 카드의 불필요한 고정 높이 제거.
- 모달을 화면 높이에 맞춰 스크롤되도록 변경.
- 시간표는 글자를 억지로 압축하지 않고 표 내부에서 가로 스크롤.
- 모바일 하단 메뉴, 본문 여백, 좁은 화면의 제목 배치 조정.
- 입력란·선택값은 왼쪽 정렬 유지.

공통 반응형 규칙을 전체 활성 페이지에 적용했습니다. 1280px 데스크톱과 320·390·768px 프레임의 주요 화면을 실제 브라우저에서 확인했으며 모든 휴대폰/브라우저 조합의 시각 검증을 완료했다는 의미는 아닙니다.

## 반드시 구분할 부분

현재 저장·로그인·권한·초대·이관은 **브라우저 내부 UI 흐름**입니다. 브라우저 저장소를 편집할 수 있으므로 운영 보안 경계가 아닙니다. 기록은 다른 기기와 공유되지 않습니다. 초대 링크도 같은 저장소에서만 유효합니다.

생기부의 확인 기능은 비어 있는 내용과 글자 수를 검사합니다. 실제 기재 요령 전체 검사나 AI 생성, 외부 제출을 수행하지 않습니다. 화면의 완료 처리는 내부 상태 변경입니다.

향후 팀원의 백엔드와 연결할 때 필요한 것은 서버 인증·인가, 데이터 영속 저장 및 동시 수정 처리, 이메일 전달, 실제 이관 정책과 감사 기록 등입니다. 이 작업은 프론트 데이터 경계를 연결하는 후속 작업으로 분리하며 현재 서버 코드를 변경하지 않습니다.

## 연동 경계

- 활성 데이터 진입점: `src/api/client.js`
- 독립 저장소: `src/data/local-client.js`, `src/data/local-store.js`
- 보관된 기존 HTTP 구현: `src/integration/http-client.js`
- 기존 HTTP 계약 테스트는 보관된 구현을 검증하고, 새 로컬 저장소 테스트는 역할 제한·미래 날짜·저장 복원·시간표 중복·초대·이관을 검증합니다.

기존 DB나 서버 데이터는 자동으로 복사·업로드·삭제하지 않습니다. 기존 API 계약 변경도 하지 않았습니다.
