# 프론트 작업 인계 확인 — 2026-10-28

이 채팅의 범위는 React 화면, 스타일, 입력 검증, 접근성, 반응형과 기존 API 호출이다. 백엔드 코드·DB·서버 프로세스·서버 설정은 수정하지 않는다. 역할 범위를 벗어난 요청은 “이 요청은 백엔드 작업이라 백엔드 채팅방에서 진행해 주세요.”라고 안내한다. 기존 연동을 되돌리거나 가짜 성공 응답·권한 우회를 추가하지 않는다. 요청 없는 브랜치 생성·커밋·푸시도 하지 않는다.

## 현재 코드에서 확인한 항목

- 활성 진입점은 `src/App.jsx`, API 화면은 `src/api/`다. 녹음 상태 화면은 `src/screens/Recording.jsx`를 사용한다.
- 교육24 공통 SVG 로고, 서버 계정 역할에 따른 메뉴, 설정 안의 로그아웃·계정 편집이 연결되어 있다.
- 초대 가입의 이메일 일치 확인, 가입 시 비밀번호 설정, 온보딩의 계정 이메일·이름·연락처·알림 설정이 있다.
- 온보딩·설정은 같은 PhoneField를 사용한다. 국가 선택 없이 국내 번호를 표시하고 숫자만 전송한다.
- 관찰 날짜 선택기에 오늘을 최댓값으로 지정하고 제출 시에도 미래 날짜를 검증한다. 개별·일괄 관찰은 별도 메뉴다.
- 홈 달력의 월 이동·오늘 버튼·선택 날짜 수업 목록, 1~9교시 주간 시간표, 학급 우선 표시가 있다. 시간표 편집은 관리자에 한정한다.
- 학년도 옆 올해 버튼이 실행 시점의 연도를 사용하고 학급·학생 선택 및 목록 페이지를 초기화한다.
- 녹음은 경과 시간·파형·일시정지·재개·종료 상태 UI만 제공한다. 마이크 접근이나 오디오 업로드는 하지 않는다.
- 작은 페이지 작업 버튼, 모바일 툴바·드로어, 스크롤 가능한 사이드바, 한국어 정보 라벨과 모션 감소 대응 스타일이 있다.
- 프론트 `.env.local`의 API_PROXY_TARGET은 8081이다. 이번 점검에서 Vite 기본값·예제 환경 파일·안내 문서의 8080도 8081로 일치시켰다. API 기본 경로는 `/api/v1`이다.

위 내용은 소스 확인 결과다. 기존 인계문의 브라우저 검증을 이번 점검에서 다시 수행한 것으로 해석하지 않는다. 미커밋 프론트 및 백엔드 변경은 보존했다.

## 남은 확인·보완 항목

- 홈은 현재 선택 날짜의 수업을 표시한다. 해당 날짜 기록 표시와 관찰·타임라인 진입을 함께 제공하는 요구는 추가 보완이 필요하다. 기존 조회 API의 날짜 필터 계약부터 확인한다.
- 여러 작성 화면에 취소 동선은 있지만, 수정 중 화면 이동 시 변경 유실 방지를 공통으로 보장하지 않는다. 화면별 보완이 필요하다.
- 시간표의 클라이언트 중복 검사는 현재 조회된 항목 범위다. 다른 학급까지 포함한 교사의 동시간 중복을 완전히 막으려면 서버 검증이 필요하다. 화면만으로 전체 중복 방지가 완료됐다고 판단하지 않는다.
- 현재 프론트 API 연동 문서에는 수업 교체 API가 없는 것으로 기록되어 있다. 최신 계약에서 구현 여부를 확인하기 전에는 교체 요청·수락·거절을 가짜 성공 처리하지 않는다.
- 기존 체크박스, 목록에 실제 데이터가 많을 때의 레이아웃, 저장 중 취소·이동 등은 후속 화면 점검 대상이다. 모든 요구가 완료된 상태로 보지 않는다.
